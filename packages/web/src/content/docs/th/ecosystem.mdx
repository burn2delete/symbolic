ชุดโครงการชุมชนที่สร้างขึ้นบน Symbolic

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Symbolic ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-symbolic](https://github.com/awesome-symbolic/awesome-symbolic) และ [symbolic.cafe](https://symbolic.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
