Una colección de proyectos comunitarios construidos en Symbolic.

:::note
¿Quieres agregar tu proyecto relacionado con Symbolic a esta lista? Envíe un PR.

También puedes consultar [awesome-symbolic](https://github.com/awesome-symbolic/awesome-symbolic) y [symbolic.cafe](https://symbolic.cafe), una comunidad que agrega el ecosistema y la comunidad.
